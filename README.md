# 명당 — 오늘 나에게 맞는 자리

자율좌석제 사무실의 좌석 컨디션 웹앱이에요. 퇴근할 때 남긴 짧은 좌석 리뷰를 모아, 오늘의 업무와 취향에 맞는 자리를 추천해요.

- 배포 주소: https://myeongdang-app.vercel.app

## 실행 방법
- 배포 주소로 접속하거나,
- 저장소를 내려받아 `index.html`을 더블클릭해요. 설치할 것은 없어요.

## 3단계로 둘러보기
1. 홈에서 "나의 취향저격 명당 TOP 3"를 봐요. "취향 수정"에서 **통화** 모드를 고르고 "이 조건으로 추천받기"를 누르면, 자리 확인 도면의 왕관과 추천 자리가 바뀌어요.
2. 왕관 자리를 눌러 취향 일치도와 항목별 점수를 보고, "예약 앱에서 예약하기" → "예약 처리하기"를 눌러요.
3. 홈에서 "체크인하기" → "이용 종료하기" → 리뷰에서 별점과 "모니터 고장났어요"를 고르고 "익명으로 등록"을 눌러요. 그 자리는 바로 수리 중으로 바뀌어 추천에서 빠지고, 알림에 수리 접수가 떠요.

## 제약과 아직 없는 기능
- 실제 예약은 사내 예약 앱에서 해요. 시연에서는 확인 창으로 대신해요.
- 서버와 DB가 없어요. 내가 남긴 리뷰·예약은 지금 쓰는 브라우저에만 저장되고, 다른 사람 화면에는 보이지 않아요.
- 도면은 17F 한 층만 있어요. 시설 담당자 화면은 아직 없어요.

## 알아 두기
- 도면과 동료 리뷰는 모두 시연용 가상 데이터예요.
- 처음 상태로 돌리려면 마이 → 시연 데이터 초기화하기를 눌러요.
