# 명당 — 오늘 나에게 맞는 자리

자율좌석제 사무실의 좌석 컨디션 웹앱이에요. 퇴근할 때 남긴 짧은 좌석 리뷰를 모아, 오늘의 업무와 취향에 맞는 자리를 추천해요.

- 배포 주소: https://myeongdang-app.vercel.app

## 실행 방법
- 배포 주소로 접속하거나,
- 저장소를 내려받아 `index.html`을 더블클릭해요. 설치할 것은 없어요.

## 알아 두기
- 도면과 리뷰는 모두 시연용 가상 데이터예요.
- 내가 남긴 리뷰·체크인은 지금 쓰는 브라우저에만 저장돼요. 처음 상태로 돌리려면 마이 → 시연 데이터 초기화하기를 눌러요.
- 실제 예약은 사내 예약 앱에서 해요. 명당은 확인, 추천, 리뷰, 수리 요청을 맡아요.
