# 명당 톤앤매너 가이드

> 원본: `명당_톤앤매너_가이드.pdf` (2쪽, 개발팀 전달용 요약 · 2026.10.02 · 초안 · 세부 수치는 개발 단계에서 조정) 텍스트 옮김
>
> ⚠️ **시안 이미지와 이 가이드가 다르면 이 가이드를 우선한다.** (6장 "기준 시안")

**명당**은 회계법인 자율좌석제 사무실의 **좌석 컨디션 플랫폼**입니다. 퇴근할 때 남긴 짧은 좌석 리뷰가 다음 사람의 자리 선택과 시설 담당자의 빠른 처리로 이어집니다.

## 1. 서비스 개요

| 사용자 | 하는 일 | 앱에 기대하는 것 |
|---|---|---|
| 리뷰 작성자 | 퇴실 직후 30초 안에 별점, 카테고리, 고장 신고를 남김 | 빠르고 부담 없는 입력 |
| 좌석 선택자 | 출근 전 내 취향에 맞는 추천 자리를 확인하고 예약 앱으로 이동 | 한눈에 보이는 추천과 그 이유 |
| 시설 담당자 | 불편·고장 신고를 확인하고 처리 상태를 바꿈 | 우선순위가 분명한 목록 |

실제 예약은 기존 사내 예약 앱에서 합니다. 명당은 확인, 추천, 리뷰, 수리 요청을 맡고 예약은 예약 앱으로 연결합니다.

## 2. 톤앤매너 키워드

### KEYWORD 1 · 따뜻한 (Warm)
좋은 자리를 먼저 써 본 동료가 슬쩍 알려주는 느낌. 주황 계열 색, 둥근 모서리, 왕관 같은 작은 보상 요소로 표현합니다.
- ○ 주황·크림색 바탕, 왕관과 별
- ○ 해요체의 친근한 말투
- × 회색 위주의 사무용 시스템 화면
- × 캐릭터·이모지 남발

### KEYWORD 2 · 한눈에 (Glanceable)
출근길 엘리베이터 안에서 3초 안에 판단할 수 있어야 합니다. 숫자보다 단계와 색, 문장보다 태그로 보여줍니다.
- ○ 온도·소음은 단계 그림 + 라벨
- ○ 상태는 색 있는 알약 표시
- × 측정값(℃, dB) 그대로 노출
- × 긴 설명문, 버튼 여러 개

### KEYWORD 3 · 믿을 수 있는 (Reliable)
회계법인 사내 서비스답게 정확하고 공정해야 합니다. 추천에는 근거, 수리에는 진행 단계, 리뷰에는 익명성을 보여줍니다.
- ○ 추천 이유 표시("따뜻함 · 화장실 20m")
- ○ 수리 접수 → 수리 중 → 완료
- × "최고의 자리!" 같은 근거 없는 과장
- × 개인을 짐작하게 하는 정보

## 3. 시각적 방향

- **색**: 주황을 주색으로, 크림색 바탕과 흰 카드를 씁니다. 다른 색은 상태 구분(완료·진행·수리 중)과 편의시설 표시에만 씁니다. 주황은 사내 브랜드 가이드의 공식 색으로 맞춥니다.
- **형태**: 카드, 버튼, 태그 모두 모서리를 둥글게 처리합니다. 한 화면의 주요 버튼은 하나만 둡니다.
- **정보 표현**: 온도는 4단계(추움·적당함·따뜻함·더움), 소음은 3단계(조용함·보통·시끄러움), 거리는 m 단위 숫자 하나로 보여줍니다. 색만으로 의미를 전달하지 않고 항상 글자 라벨을 붙입니다.
- **보상 요소**: 층마다 나에게 가장 맞는 자리 1곳에만 금색 왕관을 붙입니다. 남용하면 의미가 사라집니다.

## 4. 말투 (보이스)

명당은 **같은 층에서 일하는 친절한 선배**처럼 말합니다. 짧게 쓰고 결론(자리·숫자·상태)을 문장 앞에 둡니다.

- 해요체를 씁니다. 반말과 "~하십시오" 같은 딱딱한 말은 쓰지 않습니다.
- 한 문장은 짧게, 느낌표는 화면당 최대 1개입니다.
- 버튼은 동사로 끝냅니다("자리 확인하기", "익명으로 등록").
- 소음·불편은 **사람이 아니라 위치**의 특성으로 말합니다.

| 상황 | 이렇게 | 이렇게는 쓰지 않기 |
|---|---|---|
| 메인 인사 | 김삼일 님, 좋은 아침이에요 | 환영합니다! 오늘도 화이팅!! |
| 추천 이유 | 따뜻함 · 화장실 20m · 소음 낮음 | 당신을 위한 최고의 자리! |
| 리뷰 요청 | 오늘 이 자리 어떠셨나요? | 리뷰를 작성해 주시기 바랍니다 |
| 수리 알림 | 17F · F03 수리가 완료됐어요 | 요청하신 건이 처리되었습니다 |
| 빈 화면 | 아직 리뷰가 없는 자리예요. 첫 리뷰를 남겨 주세요 | 데이터가 없습니다 |
| 오류 | 연결이 끊겼어요. 다시 시도해 주세요 | 오류 코드 503 |
| 소음 리뷰 | 회의실 앞이라 오후에 소란스러워요 | 옆자리 사람이 시끄러워요 |

## 5. 시설 담당자 화면

같은 색과 서체를 쓰되 장식을 줄이고 **처리 우선순위가 먼저 보이게** 만듭니다. 왕관·별 같은 보상 요소는 쓰지 않습니다.

- 신고 목록 맨 앞에 상태(접수 → 수리 중 → 완료)와 경과 시간을 둡니다.
- 같은 좌석에 신고가 여러 건이면 묶어서 보여줍니다(예: "17F · C14 모니터 3건").
- 상태를 바꾸면 신고한 직원에게 바로 알림이 갑니다. 문구는 4장의 말투를 따릅니다.
- 담당자 화면도 해요체를 유지하되 더 짧고 업무적으로 씁니다(예: "처리 완료로 바꿨어요").

## 6. 개발 시 주의사항

- **로고**: 삼일PwC 로고는 브랜드팀이 제공한 공식 파일만 씁니다. 다시 그리거나 색을 바꾸지 않습니다.
- **도면**: 시안의 층 도면은 가상입니다. 실제 사무실 도면은 보안 자료이므로 총무팀 승인 후에만 반영합니다.
- **익명성**: 리뷰·신고 작성자의 이름과 사번은 어디에도 노출하지 않고 본부·연차만 보여줍니다. 인원이 적은 본부는 본부명도 숨길 수 있게 합니다.
- **리뷰 카테고리**: 정해진 목록(집중형 명당, 에어컨 직격, 콘센트 부족, 오후 햇살 강함 등)에서만 고르게 하고, 자유 의견은 텍스트로 따로 받습니다.
- **기준 시안**: 화면 01~07 이미지를 참고하되, 시안과 이 가이드가 다르면 가이드를 우선합니다.
