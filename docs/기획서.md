## 1. 선정 서비스와 선정 이유

자율좌석제 사무실에서 사용자 평가를 모아 개인 상황에 맞는 좌석을 추천하는 서비스다.

삼일회계법인은 AP 근무 시 자율좌석제로 매번 좌석을 직접 골라야 한다. 이때 생기는 문제는 세 가지다.

- **선택 비용**: 매일 아침 어디에 앉을지 판단하는 데 시간이 든다. 정보가 없어 빈자리 아무 곳을 고르게 된다.
- **교체 비용**: 앉은 뒤 에어컨 바람, 소음, 모니터 고장 등을 발견하면 짐을 옮겨 다시 자리를 찾아야 한다.
- **기준의 개인차**: 같은 자리도 사람마다, 그날 업무(집중 작업, 잦은 통화, 협업 회의)마다 평가가 다르다.

좌석 정보는 실제로 앉아 본 사람만 알고 있다. 사용 후 평가를 쌓고, 개인이 정한 우선순위로 다시 계산하면 "그날의 나에게 맞는 자리"를 처음부터 고를 수 있다. 이것이 업무 효율을 높이는 직접적인 방법이라고 판단했다.

## 2. 한 줄 문제 정의와 첫 사용자

**한 줄 문제 정의**: 자율좌석제 직원은 좌석 정보 없이 매일 자리를 골라, 자기 취향과 그날 업무에 맞지 않는 자리에서 일하거나 자리를 옮기느라 시간을 잃는다.

**첫 사용자**: 자율좌석제를 이용하는 회사의 고용인.

| 페르소나 | 상황 | 좌석에서 원하는 것 |
|---|---|---|
| 감사본부 시니어 A | 결산 시즌, 하루 종일 엑셀 집중 작업 | 조용함, 듀얼 모니터 정상, 출입구에서 먼 자리 |
| 컨설팅 매니저 B | 클라이언트 통화와 팀 미팅이 잦음 | 통화부스·회의실 근처, 개방형, 같은 팀 근처 |
| 신입 C | 자리 정보를 전혀 모름 | 실패 없는 무난한 자리, 파트너석과 적당한 거리 |

## 3. 핵심 기능 1개와 보조 기능 2개

핵심은 추천이고, 보조 기능 두 개는 추천의 재료(평가 데이터)와 사후 해결(설비 요청)을 맡는다.

| 구분 | 기능 | 설명 | 완료 기준 |
|---|---|---|---|
| 핵심 | 조건 기반 좌석 추천 | 오늘의 업무 성격과 항목별 우선순위를 입력하면, 위치 정보와 이용자 평가를 합산해 상위 3개 좌석을 추천 | 입력 후 3초 안에 추천 3석과 각 좌석의 총점·강점 표시 |
| 보조 1 | 간단 좌석 평가 | 사용 후 별점 1개 + 주요 항목 탭 선택(좋음/나쁨)으로 30초 안에 평가 | 평가가 즉시 히트맵과 좌석 총점에 반영 |
| 보조 2 | 설비 불만 자동 요청 | 의자·책상·모니터 등 같은 항목에 불만이 누적되면 설비팀에 수리 요청 | 같은 좌석·같은 설비에 7일 내 불만 3건 이상이면 요청 생성 |

## 4. 최소 구현 범위

한 층 좌석 배치도 위에 개인 우선순위 기반 명당 추천, 개인 선호도 좌석 총점, 사용 후 평가 창까지 구현한다.

**포함**

- 좌석 배치도 인터페이스: 좌석을 클릭하면 총점과 항목별 점수 표시
- 우선순위 설정: 아래 항목 중 중요한 것을 골라 순위 지정 → 명당 추천
- 좌석 총점: 전체 평균 점수와 "나의 우선순위 반영 점수" 두 가지
- 사용 후 평가 창: 퇴근 시 또는 좌석 변경 시 팝업

**평가·추천 항목** — (추가할 거, 제외 할 거 말씀해 주시면 수정하겠습니다!)

| 항목 | 데이터 출처 | 입력 방식 |
|---|---|---|
| 온도(냉,난방) | 이용자 평가 | 추움 / 적당 / 더움 |
| 소음 | 이용자 평가 | 1~5점 (조용함=5) |
| 의자·모니터 상태 | 이용자 평가 | 정상 / 불편 / 고장 (설비 요청 연동) |
| 햇빛 | 이용자 평가 | 없음 / 적당 / 눈부심 |
| 화장실 거리 | 고정 위치 정보 | 배치도 좌표로 자동 계산 |
| 통화부스 거리 | 고정 위치 정보 | 배치도 좌표로 자동 계산 |
| 파트너석 거리 | 고정 위치 정보 | 배치도 좌표로 자동 계산 |
| 개방성(폐쇄성) | 고정 위치 정보 | 좌석 유형(창가·벽면·중앙·칸막이)으로 사전 입력 |

## 5. 주요 화면 흐름 (구현하는건 1~6까지만)

사용자는 업무 모드와 우선순위만 고르면 추천 3석을 받고, 사용 후 평가가 다시 추천에 반영된다.

```
1. 업무 모드 선택 (집중·통화·협업·직접)
 → 2. 우선순위 설정 (항목 중 1~3위 지정)
 → 3. 추천 3석 (배치도 위에 명당 표시)
 → 4. 좌석 상세 (총점·항목별 점수·후기)
 → 5. 착석 체크인 (실시간 혼잡도에 반영)
 → 6. 사용 후 평가 창 (별점 + 항목 탭, 30초)
 → 점수·히트맵 갱신 (좌석 총점 재계산) → 확인 및 수리 요청 (의자·책상·모니터)
 ↺ 다음 추천에 반영 (3단계로)
```

앉은 자리가 마음에 들지 않으면 4단계에서 3단계로 돌아가 다음 추천석을 고른다. 2단계 우선순위는 첫 사용 때 한 번 정하고 이후에는 수정할 때만 연다.

## 6. 추천 로직(점수 계산) 설계 - (구현 방식에 대해서 논의 필요)

좌석 점수는 항목별 점수(0~100)에 사용자가 정한 가중치를 곱해 합산하고, 고장은 감점

- **항목 점수**: 평가 항목은 최근 30일 평균(최근 평가일수록 가중), 거리 항목은 가까울수록 높게 환산. 화장실·출입구처럼 "멀수록 좋다"고 고른 사람에게는 반대로 환산.
- **감점**: 현재 사용 중이면 추천 제외, 의자·모니터 "고장" 접수 중이면 30점 감점(혹은 제외)
- **데이터 부족 좌석**: 평가 5건 미만이면 층 평균으로 채우고 "평가 부족" 표시.
- **업무 모드 프리셋**: 집중(소음·출입구), 통화(통화부스·개방성), 협업(파트너·개방성) 세 가지를 버튼 하나로 개별 별도 가중치 자동 설정.

## 7. 성공 지표, 리스크

성공 여부는 "추천 자리에 앉은 사람이 자리를 덜 옮기는가"로 판단한다.

| 지표 | 목표 |
|---|---|
| 추천 좌석 선택률 | 추천받은 좌석 중 실제로 선택하는 비율 증가 |
| 당일 좌석 변경률 | 도입 전보다 당일 자리를 옮기는 횟수 감소 |
| 평가 참여율 | 착석 후 평가를 남기는 비율 꾸준히 유지 |
| 설비 요청 처리 | 자동 요청 건이 빠르게 처리되어 같은 불만 재발 감소 |

**리스크와 대응**

- 평가 피로 → 별점 1개 + 탭 선택만, 30초 이내.
- 명당 공유 기피(내 명당을 뺏길까 봐 좋은 자리를 평가하지 않거나 일부러 낮게 평가) → 평가는 익명 집계로 누가 어디를 좋게 봤는지 드러나지 않게 함. 추천은 실시간 사용 여부를 반영하고 상위 3석을 서로 다른 구역에서 뽑아, 평가가 공개돼도 한 자리에 사람이 몰리지 않게 함. 평가를 남긴 사람에게 "내 기준 맞춤 추천" 정확도가 올라가는 혜택을 줘 공유할 이유를 만듦. 같은 좌석의 다른 평가들과 크게 동떨어진 평가는 반영 비중을 낮춤.
- 오래된 평가로 인한 왜곡(수리·자리 배치 변경 후에도 나쁜 점수 유지) → 최근 평가에 가중치, 설비 수리 완료 시 해당 항목 점수 초기화
