# 디자인 레퍼런스 정리

> 원본: `디자인 레퍼런스.pdf` (14쪽) 요약. 이미지 레퍼런스는 원본 PDF 참고.

## 1. 기존 사내 좌석 앱 (문제 정의 시 참고) — p.2–3
- 모바일·PC 모두 좌석이 비어 있는지는 알 수 있지만, 그 외 좌석 정보(예: 좌석 컨디션)는 없음.
- → **명당이 채우려는 빈칸**: 좌석 "컨디션" 정보.

## 2. 고려대학교 도서관 예약 앱 — p.4
- 첫 화면에서 건물과 구역 선택 가능.
- 각 구역별 특성(노트북 사용 가능 여부)과 잔여 좌석 수 표시 (예: `Total: 143(144) / Available: 127`).
- 좌석 상태(예: 수리 중)에 따라 아이콘을 다르게 표시. 범례: 배정 가능 / 사용 중 / 장애인석 / 장애인배려석 / 수리 중.
- 상단 요약: `총좌석 140 · 사용중 15 · 사용가능 125`.

## 3. AI 생성 디자인 — p.5–7
- "명당 PREMIUM SEAT LOCATOR": 왼쪽 선호 조건(NOISE LEVEL / ENVIRONMENT / PROXIMITY 칩), 가운데 격자 좌석, 추천석 하나만 노란색 강조 + "MYEONGDANG" 라벨. 명당 아이콘 예시: 왕관, 하트 핀.
- "명당 / MYEONG": 상단 3단 헤더(Workspace / Current location / Selected seat), 오른쪽에 01 PREFERENCE → 02 ENVIRONMENT → 03 AI ANALYSIS(오늘의 최적 좌석 + 이유) → CONFIRM SELECTION.
- 모바일 3종: "Find your focus today." 큰 좌석 번호(A-14) + 이유 태그(WINDOW · SILENT · MORNING SUN) / "Optimal Selection: Seat 12, 98% Match Score" + 근거 4칸(자연광·트래픽·하드웨어·근접성) / 카드형 "optimal recommendation Seat B-04" + 태그 + Reserve 버튼 + 격자 맵 + 하단 플로팅 탭바.

## 4. 오늘의 명당 (AI 생성) — p.8–11
- "행운의 명당": 왼쪽 기분·환경 선택 칩, 가운데 격자, 오른쪽 "오늘의 행운 점수 99", SEAT D-04, 자연광 지수/소음 차단/럭키 아이템, "이 자리로 찜하기".
- "오늘의 명당 ✨": 오늘의 운세 카드, LUCKY ZONE·LUCKY COLOR, DAILY TIP, TODAY'S PICK C-03, 럭키 매치도·채광·소음도.
- 다크 "운세" 4종(흑금·고서 톤): 인장/원형 다이얼을 터치해 운명의 자리 확인.
- "Myeong-dang 오늘의 명당을 수집하세요": 필터·층 드롭다운, 점선 그리드 도면 위 좌석 칩(PRIME 라벨), 오른쪽 "내가 모은 명당 카드" 컬렉션, "명당 추천 받기".

> ⚠️ 톤앤매너 가이드는 **캐릭터·이모지 남발, "최고의 명당!" 같은 근거 없는 과장**을 금지한다. 레퍼런스 4의 운세·행운 콘셉트는 분위기 참고용으로만 보고, 문구는 가이드를 따른다.
