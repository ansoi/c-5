# 명당 개발 명세

> 기획서·톤앤매너·시안을 바탕으로 확정한 내용이에요. 구현은 이 문서를 기준으로 해요.
> 최종 갱신: 2026-10-03 (기본 화면 8개 완성)

## 1. 한 줄 요약
**명당 = 자율좌석제 사무실의 "좌석 컨디션" 앱.** 추천·좌석 확인·리뷰·수리 요청을 맡고, 실제 예약은 기존 사내 예약 앱으로 연결해요.

## 2. 확정한 결정 (자료끼리 다른 부분)
톤앤매너 가이드의 "시안과 가이드가 다르면 가이드 우선" 규칙으로 정했어요.

| 다른 점 | 결정 |
|---|---|
| 초록 시안 vs 주황 가이드 | **주황**: PwC 오렌지 `#D04A02`, 크림 바탕, 흰 카드 |
| 시안 "예약하기" vs 가이드 "예약은 사내 앱" | **"예약 앱에서 예약"** 버튼으로 연결만 해요. 시연에서는 바로 예약된 것으로 처리해요. 체크인은 명당 안에서 해요 |
| 온도 3단계 vs 4단계 | **4단계** (추워요·적당해요·따뜻해요·더워요) |
| 소음 1~5점 vs 3단계 | 입력과 표시는 **3단계**, 점수 계산에서만 숫자로 바꿔요 |
| 별점 (기획서·가이드엔 있음, 초록 시안엔 없음) | **별점 1개 + 항목 탭** |
| 수리 요청: 1건 즉시 vs 7일 3건 | **고장은 1건이면 바로 접수**(그 자리는 수리 중), 불편·불량은 7일 안에 3건 쌓이면 자동 접수 |
| 추천석 4개 강조 vs 왕관은 층마다 1곳 | **추천 3석을 서로 다른 구역에서**, **1위만 왕관** |
| "도보 40초" vs m 단위 | **m** (예: 화장실 32m) |
| 시안의 "AI 리뷰 요약" | AI를 쓰려면 API 키가 필요해서 규칙 위반이에요 → 리뷰 집계로 만든 **"리뷰 요약"**으로 하고, AI라고 표기하지 않아요 |
| 기획서는 한 층 vs 시안은 3개 층 | **17F 한 층부터.** 층 추가는 나중 기능으로 미뤄요 |
| 데이터 저장 | **샘플 데이터(`js/data.js`) + 각자 브라우저 저장(localStorage).** 내가 남긴 리뷰는 내 화면에서만 반영돼요. DB가 없어서 동시 접속에 안전해요 |
| 시설 담당자 화면 | **나중에.** 기본 화면을 다 만든 뒤에 추가해요 |

## 4. 데이터

### 도면 (가상, 17F) — `js/data.js`
- 좌표 단위는 m, 가로 26 × 세로 40. 창은 북쪽(위)·서쪽(왼쪽) 벽에 있어요.
- 구역 A~D, 구역마다 2줄 × 5석 = 40석. 번호는 윗줄 01~05, 아랫줄 06~10.
- 편의시설 좌표: 포커스룸, 통화부스, 탕비실·정수기, 회의실, 파트너석, 화장실(오른쪽 벽), 복사실, 출입구·엘리베이터(아래쪽).
- 거리는 통로를 따라 걷는 거리(가로 + 세로)로 계산해서 반올림해요.

### 좌석
| 필드 | 뜻 |
|---|---|
| `id` | `A01` ~ `D10` (화면에는 `17F · A01`) |
| `zone`, `row`, `col`, `x`, `y` | 구역, 줄, 칸, 좌표 |
| `type` | `window`(창가) / `wall`(벽면) / `center`(중앙) / `partition`(칸막이) |
| `windowSide` | `north` / `west` / `corner` / `null` |
| `dual`, `outlets`, `acDirect` | 듀얼 모니터, 콘센트 수, 에어컨 바람 직격 |
| `dist` | 편의시설까지 거리(m): `wc`, `booth`, `pantry`, `meeting`, `partner`, `copy`, `entrance`, `focus` |

### 리뷰
`{ id, seatId, daysAgo, stars(1~5), temp(0~3), noise(0~2), light(0~2), chair(0~2), monitor(0~2), tags[], text, dept, year, checkIn, checkOut }`
- 단계 값: 온도 추움·적당·따뜻·더움 / 소음 조용·보통·시끄러움 / 햇빛 어두움·적당·눈부심 / 의자·모니터 좋음·불편(불량)·고장
- 샘플 리뷰 537건은 고정 시드로 만들어요. 누가 열어도 같아요. 내가 남긴 리뷰는 `date`(날짜 키)로 저장되고, 합칠 때 `daysAgo`로 바뀌어요.
- 카테고리: 집중형 명당, 듀얼모니터 맛집, 채광 좋음, 오후 햇살 강함, 에어컨 직격, 콘센트 부족, 오가는 길목

### 수리 요청 — `js/tickets.js`
`{ id, seatId, item(chair/monitor/desk/outlet), kind(broken/auto/report), summary, mine, events{received, progress, done}, etaDays }`
- 고장 리뷰 1건 → `broken` 요청 → 그 자리는 **수리 중**(추천 제외)
- 불편·불량 7일 안에 3건 → `auto` 요청 → 처리될 때까지 **30점 감점**
- 수리 완료 → 그 설비의 완료 전 평가는 점수에서 빼요

### 내 상태 (브라우저 저장소, 키 앞에 `md.`)
| 키 | 내용 |
|---|---|
| `prefs` | `{ mode, priorities[최대 3] }`. 없으면 집중 모드 기본값 |
| `mySeat` | `{ date, seatId, from, to, status(reserved/checkedIn/done), checkInAt, checkOutAt, reviewed }`. 오늘 기록이 없으면 시연용 B07 예약 |
| `myReviews` | 내가 남긴 리뷰 |
| `myTickets` | 내가 직접 넣은 신고 |
| `lastSession` | 오늘 마지막으로 이용을 마친 자리 `{ seatId, checkInAt, checkOutAt, reason(checkout/move), reviewed }` |
| `settings` | `{ hideDept }` — 리뷰에 본부 이름 숨기기 |
| `events` | 내 활동 기록 (예약·체크인·리뷰), 알림에 써요 |
| `reported` | 신고해서 가린 리뷰 id |
| `alertsSeenAt` | 알림을 마지막으로 본 시각(ms). 이후 생긴 알림이 '새 알림' |
| `version` | 저장 구조 버전. 바꾸면 예전 값이 지워져요 |

## 5. 추천 로직 — `js/score.js`
**취향 일치도 = 항목 점수(0~100)의 가중 평균 − 감점**
- 우선순위 1·2·3위 조건의 가중치는 5·3·2예요.
- 고르지 않아도 늘 조금씩 보는 기본 항목: 동료 만족도(별점) 1.5, 설비 상태 1, 온도 0.75, 햇빛 0.5
- 평가 항목은 최근 30일만 보고, 최근일수록 크게 반영해요 (14일마다 절반).
- 평균에서 크게 동떨어진 평가는 절반만 반영해요.
- 평가 5건 미만이면 층 평균으로 채우고 "평가 부족"을 표시해요.
- 거리 항목은 가까울수록 높게 환산하고, "멀리"를 고르면 반대로 환산해요.
- 개방성: 중앙 100, 창가 70, 벽면 40, 칸막이 0. "칸막이·벽면 자리"를 고르면 반대로 환산해요.
- 사용 중·수리 중인 자리는 추천에서 빼요. 불만 접수 중이면 30점을 감점해요.
- 추천 3석은 서로 다른 구역에서 골라요. 1위만 왕관을 붙여요.
- 전체 평균 점수 = 동료 별점 평균(★)

| 업무 모드 | 우선순위 기본값 |
|---|---|
| 집중 | 조용한 자리 → 출입구에서 멀리 → 듀얼 모니터 |
| 통화 | 통화부스 가까이 → 트인 자리 → 회의실 가까이 |
| 협업 | 파트너석 가까이 → 트인 자리 → 회의실 가까이 |
| 직접 | 내가 고른 순서 |

추천 이유는 우선순위 조건을 그대로 풀어서 보여 줘요. 예: "소음 낮음 · 출입구에서 36m · 듀얼 모니터"

## 6. 시연 흐름 (P.13 재현 경로 3단계)
1. 홈에서 "나의 취향저격 명당 TOP 3"를 봐요. "취향 수정"에서 **통화** 모드를 고르고 "이 조건으로 추천받기"를 누르면, 자리 확인 도면의 왕관과 추천 자리가 바뀌어요.
2. 왕관 자리를 눌러 취향 일치도와 항목별 점수를 보고, "예약 앱에서 예약하기" → "예약 처리하기"를 눌러요. 홈의 "오늘 내 자리"가 바뀌어요.
3. 홈에서 "체크인하기" → "이용 종료하기" → 리뷰에서 별점과 "모니터 고장났어요"를 고르고 "익명으로 등록"을 눌러요. 그 자리는 바로 수리 중이 되어 추천에서 빠지고, 알림에 수리 접수가 떠요.

처음 상태로 돌리려면 마이 → 시연 데이터 초기화하기를 눌러요.
